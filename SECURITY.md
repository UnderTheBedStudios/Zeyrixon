# Security Policy

If you discover a security vulnerability in Zeyrixon, please do not open a public issue. Instead, report it privately using one of the methods below.

## Reporting a vulnerability

- Preferred: Email `peteraymondiv@gmail.com` with the subject `Zeyrixon security report`.
- Alternative: Create a private, confidential issue on GitHub and mention `@UnderTheBedStudios` as the maintainers.

Include the following in your report where possible:

- A clear summary of the vulnerability and its impact
- Steps to reproduce, including sample code and exact commands
- Affects versions / commit SHA
- Any suggested fixes or mitigation steps

## Response process

We aim to:

- Acknowledge receipt within 3 business days
- Triage and confirm the issue within 7 business days
- Provide a remediation plan and timeline

We will coordinate disclosure with the reporter, and will credit the reporter unless they request anonymity.

## Supported releases

List of maintained branches and versions will be added here. For urgent fixes we may provide a patch branch and CVE assignment where appropriate.

## Disclosure

After a fix is available, we will publicly disclose the vulnerability and the fix. If you prefer to remain anonymous, tell us in your report and we will honor that request.
